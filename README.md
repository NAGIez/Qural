# Qural

**Qural** (Құрал — «инструмент») — программа для Windows в трее: цвет мониторов, громкость программ, скриншоты, запись экрана и объединение интернет-подключений — по горячим клавишам и с кнопок Ulanzi Deck.

Текущая версия — **1.0.2** ([что нового](../../releases/tag/v1.0.2)).

- **Регулировка цвета** — профили мониторов: яркость, контраст, гамма (как в Панели NVIDIA), цифровая интенсивность и оттенок NVIDIA.
- **Микшер звука** — громкость каждой программы своими клавишами, «активное окно».
- **Скриншоты** — PrtSc: область, окно, экран; стрелки, текст, размытие, номера шагов, пипетка; подсветка области — затемнить или размыть всё вокруг.
- **Запись экрана** — область, окно или экран; кодирует видеокарта (NVENC / AMF / QSV), звук ПК и микрофон, шумоподавление RNNoise, отсчёт перед стартом; редактор: обрезка, вырезка, кадр, громкость до 200 % (слышно сразу в просмотре), MP4 / MKV / GIF / MP3.
- **Сеть** — все подключения сразу: кабель, Wi-Fi и раздача с телефона работают как одно (внутри — [net-merge](https://github.com/net-merge/net-merge), MIT). Скорость и трафик каждого подключения за день и месяц, лимиты, автопауза, когда подключение одно; какая программа сколько качает и через какое подключение; замер скорости по методу Speedtest — каждое подключение отдельно и все вместе.
- **Плагины Ulanzi Studio** — громкость, профиль цвета, скриншот и запись (с анимацией: выделение, отсчёт, запись с таймером, пауза; долгое нажатие «Скриншота» — запись), «Сейчас играет», нагрузка ПК, «Сеть», Discord, Claude.
- **Автообновление** — Qural раз в 12 часов проверяет релизы на GitHub, напоминает в трее и обновляется в один щелчок («Общие» → «Обновления»).

## Установка

Скачайте `QuralSetup-<версия>.exe` из [Releases](../../releases) и запустите. Права администратора не нужны: Qural ставится в
`%LOCALAPPDATA%\Programs\Qural`, ярлык — в «Пуске», удаление — через «Параметры → Приложения». Плагины для Ulanzi Studio
ставятся сами, если она установлена. При первом запуске Qural спросит, какие инструменты включить (по умолчанию — ни один);
выключенные инструменты не показываются в меню, включить их можно на «Главной» или в «Общих».

Установщик пока не подписан, поэтому Windows может показать окно SmartScreen «Неизвестный издатель» — «Подробнее» →
«Выполнить в любом случае». С версии 1.0.1 обновления приходят сами; 1.0.0 обновите вручную — поставьте новую версию поверх,
настройки сохранятся.

Нужно: Windows 10 (2004 и новее) или 11, x64; .NET Framework 4.8; Microsoft Edge WebView2 Runtime (в Windows 11 уже есть,
установщик подскажет, если его нет). Запись экрана на Windows 10 пока не проверялась.

Настройки: `%APPDATA%\Qural\` (`color.json`, `sound.json`, `general.json`, `shot.json`, `rec.json`, `net.json`).

«Сеть» при первом включении один раз просит права администратора: Qural создаёт задачу Windows «Qural net-merge», которая
дальше запускает сетевой модуль без окна UAC. Удаление Qural убирает и задачу.

## Стек

| Часть | Чем сделано |
|---|---|
| Программа | C# 5, .NET Framework 4.x, WinForms; собирается встроенным в Windows `csc.exe`, без NuGet и Visual Studio |
| Окно настроек и редактор | Microsoft WebView2 (SDK 1.0.4314), HTML / CSS / JavaScript без фреймворков, своё оформление GlassWise UI |
| Цвет | Гамма-таблица Windows (`SetDeviceGammaRamp`), NVIDIA NVAPI — цифровая интенсивность и оттенок |
| Звук | Windows Core Audio (WASAPI, сессии громкости программ) через COM |
| Скриншоты | GDI+, Win32 / DWM; рисование и размытие — свои |
| Запись экрана | FFmpeg 9.1 (сборка gyan.dev): захват Windows Graphics Capture (`gfxcapture`), кодеки H.264 / HEVC / AV1 на NVENC / AMF / QSV или x264 / x265; звук ПК и микрофона — WASAPI loopback, передаётся в FFmpeg по именованным каналам; шумоподавление — RNNoise (`arnndn`) или `afftdn` |
| Сеть | net-merge 0.4.2 (Wintun) в режиме без окна; трафик программ — ETW `Microsoft-Windows-Kernel-Network`; замер скорости — серверы Speedtest (Ookla), запасной — Cloudflare; запросы через конкретное подключение — `IP_UNICAST_IF` |
| «Сейчас играет», нагрузка ПК | Windows Media Control (WinRT), NVML из драйвера NVIDIA, LibreHardwareMonitor (если запущен) — температура процессора |
| Плагины деки | Node.js из Ulanzi Studio, `ws`; связь с Qural — именованный канал с JSON; картинки кнопок и GIF-анимации рисует Qural |
| Интеграции | Spotify Web API («Любимые треки»), Discord RPC, хуки Claude Code |
| Установщик и обновления | Один exe на WinForms с архивом внутри (`System.IO.Compression`); обновления — GitHub Releases API, проверка SHA-256 |

## Сборка

```powershell
Projects\Qural\build.ps1                 # Qural → App\ (FFmpeg и net-merge скачаются сами при первой сборке)
Projects\QuralSetup\build-setup.ps1      # установщик → dist\QuralSetup-<версия>.exe
```

Ничего ставить не нужно: собирается встроенным в Windows компилятором C# (.NET Framework 4.x). Перед сборкой закройте Qural.
Версия берётся из `Projects\Qural\src\Uninstaller.cs` (`AssemblyVersion`); для обновления выложите установщик в релиз с тегом
`v<версия>` — установленные копии найдут его сами.

| Папка | Что внутри |
|---|---|
| `Projects\Qural` | Исходники Qural (`src`), страница окна (`src\ui`, GlassWise UI), значки для деки, `build.ps1`. Подробности — в его README. |
| `Projects\QuralDeck` | Плагины Ulanzi Studio и `install.ps1` для разработки. |
| `Projects\QuralSetup` | Установщик: один exe с программой и плагинами внутри. |
| `App`, `dist` | Результаты сборки (в репозиторий не попадают). |

Сторонние компоненты: FFmpeg (сборка [gyan.dev](https://www.gyan.dev/ffmpeg/builds/), GPL) — в установщике и в `App\ffmpeg`,
[net-merge](https://github.com/net-merge/net-merge) (MIT, с Wintun) — в `App\net-merge`,
модель RNNoise [arnndn-models](https://github.com/richardpl/arnndn-models), Microsoft WebView2 SDK, `ws` (MIT) в плагинах.
