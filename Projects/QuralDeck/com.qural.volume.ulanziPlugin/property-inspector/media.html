Показывает, что играет сейчас в любом плеере Windows — Spotify, браузер, Яндекс Музыка: обложку, название, исполнителя и позицию в треке.

Нажатие — пауза / играть, два раза — следующий трек, три раза — предыдущий, держать — лайк в Spotify («Любимые треки»). Крутилка: поворот — следующий / предыдущий трек, нажатие — так же, как у кнопки.
Длинное название бежит строкой, при смене трека обложка уезжает и въезжает новая.

Лайки — один раз настроить:
  1. Откройте developer.spotify.com/dashboard → Create app, любое имя и описание.
  2. В Redirect URIs добавьте http://127.0.0.1:8899/callback, отметьте Web API, сохраните.
  3. Скопируйте Client ID (секрет не нужен), вставьте сюда и нажмите Войти в Spotify — в браузере нажмите «Согласен».
Ключи хранит только Qural на этом компьютере (%APPDATA%\Qural\spotify.json). Нужен запущенный Qural.
