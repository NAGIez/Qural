# Qural (Құрал — «инструмент»)

Одна программа вместо ColorSwitch и MixKeys: профили цвета мониторов и громкость программ по горячим клавишам.
Одна иконка в трее, одно окно в оформлении GlassWise UI со своей шапкой.

## Запуск
`G:\Project\Qural\App\Qural.exe` — иконка (три RGB-регулятора) в трее. Стоит в автозагрузке: запускается тихо, только иконкой.
Переносите папку `App` целиком: рядом с exe лежат DLL WebView2 и папка `ui`.

## Окно
Слева меню: «Главная», группы «Цвет ˅» (профили) и «Звук ˅» («Активное окно» и программы), «Общие». Группы сворачиваются стрелкой.
- **Главная** — оба инструмента с переключателями вкл/выкл, быстрые действия (профили цвета, сброс мониторов), все сочетания клавиш одним списком и есть ли конфликты.
- Выключенный инструмент не держит клавиши; выключенный «Цвет» возвращает мониторы к стандартным значениям. Вкл/выкл — на главной, на странице инструмента, в «Общих» и в меню трея.
- **Цвет** — профили: яркость, контраст, гамма, цифровая интенсивность, оттенок для каждого монитора; клавиша на каждый профиль и «следующий профиль».
- **Звук** — программы из микшера: громче / тише / без звука, шаг 1–25 %, несколько имён exe; «Активное окно» — для программы в фокусе (кроме тех, у кого своя строка).
- **Скриншоты** — аналог Lightshot (см. ниже): клавиши, папка, формат PNG/JPG и качество, курсор на снимке, запоминать рамку, уведомления.
- **Общие** — автозапуск, что делает щелчок по иконке в трее (открыть окно или следующий профиль цвета), пояснения.

Клавиши цвета и звука проверяются вместе: одно сочетание не достанется двум действиям — при переназначении Qural скажет, у кого забрал.

## Команды (Ulanzi Deck, Stream Deck, ярлыки)
```
Qural.exe --profile "Обычный" | --profile 2 | --profile next
Qural.exe --reset-colors
Qural.exe --volume Spotify up | down | +10 | -10 | 50 | mute     (вместо имени: active — программа в фокусе)
Qural.exe --color on | off | toggle        Qural.exe --sound on | off | toggle
Qural.exe --open
Qural.exe --shot | --shot full | --shot window   (область / монитор под курсором / окно в фокусе)
```
Если Qural уже работает, команда передаётся ему и выполняется примерно за 25 мс, второй запуск сразу закрывается.
Если не работает, Qural запускается в трей (без окна) и выполняет команду.

**Ulanzi Deck:** «Общие» → «Создать ярлыки для деки» — в папке `App\Ярлыки для деки` появится ярлык на каждую команду.
В Ulanzi Studio перетащите на кнопку действие **System → Open** и выберите нужный ярлык.

## Громкость на кнопках деки (плагин Ulanzi Studio)
Плагин «Qural — громкость» (`G:\Project\Qural\Projects\QuralDeck`, установка — `install.ps1`) показывает на кнопке или экране
крутилки, сколько сейчас стоит громкость программы, и меняет её. В Ulanzi Studio: категория **Qural** → действие
**«Громкость программы»** — на кнопку или крутилку; в настройке выбрать программу (или «Активное окно»).
- Кнопка: значок программы, проценты, полоска. Нажатие — без звука (или громче/тише — выбирается).
- Крутилка: кольцо громкости вокруг значка; вправо — громче, влево — тише, нажатие — без звука. Зажать и крутить —
  следующий / предыдущий трек этой программы (Spotify, браузер — любой плеер Windows); у программы плеера нет — громкость крупным шагом.
- **«Сейчас играет»** (та же категория): обложка, название, исполнитель и полоска позиции того, что играет в любом плеере
  Windows (Spotify, браузер, Яндекс Музыка — системные медиаэлементы управления, GSMTC). Кнопка — пауза / играть;
  крутилка — поворот листает треки, нажатие — пауза, на экране обложка в кольце позиции. Qural читает плеер в своём
  потоке (`src\Media.cs`) раз в секунду, только пока такая кнопка видна на деке.
  Нажатия: 1 — пауза, 2 — следующий, 3 — предыдущий, держать ≥ 0,6 с — лайк в Spotify («Любимые треки»; сердечко
  на обложке: зелёное — в любимых). Для лайков один раз: developer.spotify.com/dashboard → Create app, Redirect URI
  `http://127.0.0.1:8899/callback`, Web API; Client ID вставить в настройку кнопки → «Войти в Spotify» (вход PKCE,
  без секрета; `src\Spotify.cs`, ключи — `%APPDATA%\Qural\spotify.json`).
- Значки — белые PNG 196×196 на прозрачном фоне в папке `App\deck-icons` (или `%APPDATA%\Qural\deck-icons`), имя файла = имя exe:
  `spotify.png`, `discord.png`. Нет значка — рисуется динамик с названием программы. Новые файлы подхватываются за 10 секунд.
- Громкость берётся у Qural через канал `\\.\pipe\Qural.Deck.<пользователь>`. Qural не запущен или закрылся — на кнопках логотип Qural с жёлтым «!»
  (`QuralDeck\tools\make-qural-offline.ps1`), на крутилках подпись «Qural не отвечает».
- Пока на деке не видно этих кнопок, Qural ничего не опрашивает; видно — сверяется с микшером раз в секунду.

## Управление Claude с деки (плагин «Qural — Claude»)
`G:\Project\Qural\Projects\QuralDeck\com.qural.claude.ulanziPlugin`, установка — `install.ps1 claude` (оба плагина — `install.ps1`).
В Ulanzi Studio категория **Qural — Claude**, кнопки можно собрать в папку:
- **Статус Claude** — пиксельный персонаж Claude с анимацией: свободен, думает, работает, ждёт вас, разрешить?, готово, ошибка, нет связи.
  Нажатие — вывести окно Claude вперёд.
- **Разрешить / Отклонить** — когда Claude просит разрешение, кнопки становятся белыми. Нажатие отвечает на запрос.
  Не нажали за 15 секунд — запрос появляется в окне Claude как обычно.
- Статус показывает **чат, открытый в приложении Claude**: ваш ход (курсор мигает), думает (облачко мысли), работает
  (печатает на ноутбуке), разреши? (табличка «?»), выберите (Claude предлагает варианты — три карточки), готово
  (конфетти, через минуту — «ваш ход»), ошибка, нет связи. Подписи — пиксельным шрифтом. Короткое нажатие — сценка
  «Claude кодит за монитором», долгое (полсекунды) — открыть окно Claude.
- **Диктовка** показывает, включена ли: белая плашка с волнами и красной точкой, пока приложение Claude занимает
  микрофон (Qural смотрит отметку Windows `ConsentStore\microphone`), серый перечёркнутый микрофон — когда нет.
- **Сжать?** — контекст текущей сессии занят на 70 % и больше: персонаж раздувается и пыхтит (пора сделать /compact).
  Контекст считается по журналу сессии (`transcript_path` из хуков). Размер окна плагин узнаёт сам (модель ушла
  за 200 тыс. токенов — значит, окно 1 млн; запоминается в `ctxwin.json`), либо задаётся в настройке кнопки статуса.
- **Лимиты** (кнопка и крутилка) — 5 часов, неделя, Fable (лимит по модели) и контекст сессии. В настройке:
  «Показывать» — все вместе или одно окно; «Вид» одного окна — цифра или цифра с маленьким Claude, который ведёт себя
  по заполненности (до 50 % спокоен, до 70 % шагает, до 90 % раздувается и потеет, дальше — на пределе и трясётся);
  нажатие на окно «контекст» — вопрос «СЖАТЬ?», второе нажатие за 5 с — Qural выводит окно Claude вперёд, вводит
  `/compact` в поле сообщения (заменяя недописанное) и нажимает Enter;
  нажатие на другое одно окно с персонажем — забег: персонаж бежит по трассе до своего процента (счётчик растёт вместе с ним),
  на финише радуется / запыхался / без сил, через ~4 с кнопка возвращается к обычному виду; в остальных видах нажатие
  (и поворот крутилки) переключает окна по кругу.
  Источники: «С сервера» (вкл. по умолчанию) — раз в 5 минут `plugin\usage.js` спрашивает проценты у
  `api.anthropic.com/api/oauth/usage` (неофициальный адрес) по ключу входа Claude Code из `~/.claude/.credentials.json`;
  ключ живёт 8 часов, истёк — плагин запускает `claude -p --model haiku ok` (≈ $0,003 по цене API), и Claude Code
  обновляет ключ сам. Ключ никуда, кроме Anthropic, не уходит и не сохраняется. Ещё лимиты присылает строка состояния
  терминального Claude Code (`hook\statusline.cjs`); приложение Claude её не вызывает.
- **Крутилки:** «Статус» — поворот переключает сессии (Ctrl+Tab), нажатие открывает Claude; «Разрешить / отклонить» —
  вправо да, влево нет, на экране — что просит Claude; «Лимиты» — поворот переключает окно.
- **Часы** — время пиксельным шрифтом (двоеточие мигает), день недели и дата; для широкого экрана шрифт поменять нельзя — это системный режим Ulanzi.
- **Стоп** белый, когда Claude думает или работает, серый — когда останавливать нечего.
- Контекст берётся у чата, открытого в приложении Claude (`lastFocusedAt` в `%LOCALAPPDATA%\Claude-Data\…\claude-code-sessions\…\local_*.json`).
- **Браузер** (Ctrl+Shift+B), **Стоп** (Esc), **Новый чат** (Ctrl+N), **Диктовка** (Ctrl+D) — окно Claude выводится вперёд и нажимается клавиша.
  Клавиши можно поменять в настройке кнопки. Для них нужен запущенный Qural (команда `keys` в канале деки).

Как работает: статус и запросы разрешения приходят от хуков Claude Code — при установке `hook\setup.cjs` прописывает их
в `~/.claude/settings.json` (копия файла — `settings.json.bak-<дата>`; хуки старого AgentDeck при этом убраны).
Обычные события идут в фоне и Claude не задерживают; `PermissionRequest` ждёт ответа деки до 15 с.
Плагин не запущен — хуки сразу выходят. Убрать хуки: `node "%APPDATA%\Ulanzi\UlanziDeck\Plugins\com.qural.claude.ulanziPlugin\hook\setup.cjs" remove`.
Статус виден для сессий вкладки Code; обычный чат Claude хуков не вызывает.
Картинки рисует `tools\ClaudeTiles.cs` (`tools\make-icons.ps1`): PNG кнопок и GIF-анимации статуса.
Широкий экран деки плагинам недоступен (там только часы, нагрузка ПК и своя картинка) — для него есть
`assets\claude_wide.gif`: персонаж проходит по экрану и машет. Ставится в Ulanzi Studio: широкий экран → «Своя картинка / GIF».
Ещё две сцены для широкого экрана: `assets\claude_show.gif` — Claude занимается делами (чай, монитор, цветок) и
`assets\claude_autumn.gif` — осенний закат: Claude со спины сидит на склоне у моря, рядом кружка чая с паром, с дерева падают листья.

## Discord на деке (плагин «Qural — Discord»)
Папка `QuralDeck\com.qural.discord.ulanziPlugin`, установка — `QuralDeck\install.ps1 discord`. Qural для него не нужен.
Кнопка показывает голос Discord: **обычный** (белая плашка), **микрофон заглушен** (красный перечёркнутый микрофон),
**звук выключен** (красные перечёркнутые наушники); серые — Discord не запущен, с «!» — нужна настройка или разрешение.
Нажатие — заглушить/вернуть микрофон, долгое (≥ 0,6 с) — выключить/вернуть звук. На крутилке: вправо — вернуть, влево — заглушить.
Связь — локальный канал Discord RPC (`\\.\pipe\discord-ipc-N`). Discord отдаёт голос только своему приложению, поэтому
один раз: discord.com/developers → New Application → OAuth2: Client ID, Reset Secret, Redirects `http://localhost`;
ID и секрет вставить в настройки кнопки и разрешить доступ в окне Discord. Секрет и токены — в `%APPDATA%\Qural\deck-discord.json`.
Картинки рисует `tools\DiscordTiles.cs` (`tools\make-discord-icons.ps1`).
**«Discord — кто говорит»** — аватар того, кто сейчас говорит в вашем голосовом канале, с зелёным кольцом и именем
(говорят несколько — «+N»); все молчат — аватары участников и название канала; не в канале — «НЕ В КАНАЛЕ».
Нажатие — как у кнопки голоса (микрофон, долгое — звук). Данные — те же RPC-события (`GET_SELECTED_VOICE_CHANNEL`,
`SPEAKING_START/STOP`, `VOICE_STATE_*`), аватары — с `cdn.discordapp.com` (PNG 128 px, разбирает `plugin\png.js`).

### Нагрузка ПК на деке
Действие **«Нагрузка ПК»** (категория **Qural**): пиксельным шрифтом три строки — CPU (загрузка, `GetSystemTimes`),
GPU (загрузка и температура NVIDIA через `nvml.dll` из драйвера), RAM (занято G и %). Перегрев — жёлтым от 75°,
красным от 85°; память — от 80 % и 90 %. Нажатие ничего не делает. Температуру процессора Windows без драйвера
не отдаёт — если запущен LibreHardwareMonitor (или OpenHardwareMonitor), Qural берёт её из его WMI сам.
Опрос (`src\Stats.cs`) раз в секунду, только пока кнопка видна; рисует плагин (`plugin\stats.js`).

### Профиль цвета на деке
Там же, в категории **Qural**, — действие **«Профиль цвета»**: монитор с номером профиля, без надписей.
По умолчанию «Следующий по кругу»: на кнопке номер текущего профиля, нажатие — следующий (1 → 2 → 1).
Можно выбрать конкретный профиль: кнопка белая, когда он включён, серая — когда нет. Крутилка: вправо/влево — следующий/предыдущий.

### Скриншот на деке
Действие **«Скриншот»** (только кнопка): в настройке — что снимать: область (откроется рамка с рисованием), весь экран
или окно в фокусе (сразу в папку и буфер).

## Скриншоты (аналог Lightshot)
`src\Shot.cs` — снимок, экран выделения и рисования; `src\ShotPage.cs` и `ui\shot.js` — страница настроек.
- **PrtSc** — выделить область: протянуть рамку; щелчок без протягивания — окно под курсором; Ctrl+A — монитор под курсором, ещё раз — все.
  Рамку двигают и тянут за края; стрелки — на 1 точку (Shift — на 10, Ctrl — размер). Рядом размер рамки.
- Рука: двигать нарисованное, ручки по краям — растянуть (у надписи — размер шрифта, у номера — круга), двойной щелчок по надписи — править, Delete — удалить; подсветка области — всё вокруг затемняется.
- Рисование: карандаш, линия, стрелка, прямоугольник, окружность, маркер, текст, размытие (квадратами), подсветка, номера шагов, цвет (11 цветов
  и любой свой), отмена. Колёсико — толщина, Shift — ровно (45°, квадрат, круг), правый щелчок — выйти из инструмента.
- Пипетка: пока рамки нет, у курсора лупа ×10 и код цвета, **C** — скопировать код.
- Ctrl+C / Enter / двойной щелчок — в буфер (картинкой и PNG), Ctrl+S — сохранить (с вопросом или сразу в папку), Esc — закрыть.
- **Shift+PrtSc** — монитор под курсором, **Ctrl+PrtSc** — окно в фокусе: сразу файлом в папку (по умолчанию «Изображения\Qural») и в буфер.
- Уведомление после копирования и сохранения; щелчок по нему открывает папку с файлом.
- Нет из Lightshot: загрузка на prntscr.com, соцсети, поиск похожих картинок, печать, прокси.
- PrtSc нужен свободным: закройте Lightshot; в Windows 11 выключите «Открывать „Ножницы“ клавишей Print Screen» (страница подскажет).
- Полноэкранные игры в эксклюзивном режиме при открытии рамки сворачиваются; быстрые снимки (экран, окно) их не трогают, но такие игры
  через Windows могут сниматься чёрным.

## Запись экрана
`src\Rec.cs` — запись, панель, отсчёт; `src\AudioCapture.cs` — звук ПК и микрофон (WASAPI); `src\Editor.cs` + `ui\editor.*` — редактор и сохранение;
`src\RecPage.cs` + `ui\rec.js` — настройки. FFmpeg 9.1 (сборка gyan.dev essentials, GPL) и модель RNNoise `std.rnnn` лежат в `ffmpeg\`,
`build.ps1` кладёт их в `App\ffmpeg`.
- **Ctrl+Alt+R** — выбрать, что записывать (рамка, щелчок по окну, Ctrl+A — экран), Enter — отсчёт 3-2-1 и запись; ещё раз — стоп.
  **Ctrl+Alt+P** — пауза (новый кусок, при остановке склеиваются без перекодирования).
- Картинка: Windows Graphics Capture (`gfxcapture`) → кодировщик видеокарты (NVENC / AMF / QSV) без копирования в обычную память,
  как в OBS: на RTX 5080 FFmpeg ~1 % ядра, Qural ~2 %. Окно пишется, даже если его перекрыть. Кодеки: H.264, HEVC, AV1 (видеокарта)
  и H.264 / HEVC на процессоре; Qural сам проверяет, какие работают.
- Звук: ПК (loopback) и микрофон — 48 кГц, без потерь (FLAC), отдельными дорожками; громкость и шумоподавление (RNNoise или мягкое FFT)
  применяются при сохранении.
- Панель записи (время, уровень звука, пауза, стоп), рамка области и отсчёт на запись не попадают (WDA_EXCLUDEFROMCAPTURE).
- Редактор: обрезка начала/конца (жёлтые ручки), выделить кусок протяжкой или I/O → «Вырезать» (Del) или «Оставить только это»,
  кадрирование рамкой, громкость и выключение дорожек, шумоподавление слышно сразу, «Скопировать кадр». Сохранение: MP4, MKV, GIF,
  M4A, MP3; без правок видео не перекодируется. После сохранения — «Копировать файл» (вставить в чат).
- Исходники 5 последних записей — `%LOCALAPPDATA%\Qural\rec`, их можно снова открыть из «Последних записей». Журнал — `%APPDATA%\Qural\rec.log`.
- Команды: `--rec` (начать/стоп), `--rec start screen|window|region`, `--rec pause`. Дека: действие «Запись экрана».
## Настройки
`%APPDATA%\Qural\`: `color.json`, `sound.json`, `general.json`, `shot.json`, `rec.json`. Сохраняются сами сразу после изменения.
При первом запуске взяты из `%APPDATA%\ColorSwitch\config.json` и `%APPDATA%\MixKeys\config.json` (старые файлы не тронуты).

## Ограничения
- Яркость/контраст/гамма — как в Панели NVIDIA: таблицей в драйвере (те же ползунки и та же формула; игры на весь экран её не сбрасывают).
  Без NVIDIA — через гамма-таблицу Windows; там слишком сильные значения Windows не даёт поставить.
  Снять ограничение (PowerShell от администратора, затем перезагрузка):
  `reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ICM" /v GdiIcmGammaRange /t REG_DWORD /d 256 /f`
- На этой сборке Windows основной регулятор громкости программы недоступен — меняется громкость её каналов:
  звук тише/громче работает, но ползунок в микшере Windows не двигается.

## Нагрузка
В фоне нет опросов и таймеров — только ожидание клавиш. Окно (WebView2) создаётся при открытии и закрывается вместе с ним.

## Сборка
`build.ps1` — встроенный компилятор .NET Framework, ничего ставить не нужно. Готовая программа собирается в `G:\Project\Qural\App` (перед сборкой закройте Qural: трей → Выход), промежуточные файлы — в `obj`.
`lib` — Microsoft.Web.WebView2 1.0.4314.35 (nuget.org), `src\ui\glasswise` — файлы GlassWise UI, `tools\IconGen.cs` — логотип.
