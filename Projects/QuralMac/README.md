# Qural для Mac

Программа в строке меню macOS: скриншоты с рисованием и запись экрана. Только эти два инструмента —
цвета мониторов и громкости программ на Mac нет.

Статус: **0.1.1, тестовые сборки** — проверяется на Apple Silicon.

## Что умеет

**Скриншоты**
- ⌃⌥S — выделить область (щелчок без рамки — весь экран), рамку можно двигать и тянуть за ручки.
- Рисование: карандаш, линия, стрелка, прямоугольник, овал, маркер, текст, размытие (пиксели), номера шагов; 8 цветов; ⌘Z — отменить.
- ⌘C или Enter — в буфер, ⌘S — сохранить в `~/Pictures/Qural` (PNG или JPEG), Esc — закрыть.
- ⌃⌥F — весь экран под курсором сразу в папку (и в буфер).

**Запись экрана**
- ⌃⌥R — весь экран под курсором (ещё раз — остановить), ⌃⌥A — область рамкой, ⌃⌥W — окно (системный выбор окна).
- Кодирует аппаратный кодировщик Mac: HEVC или H.264, 24 / 30 / 60 кадров; звук системы и микрофон; отсчёт 3-2-1.
- Файлы — `~/Movies/Qural/*.mov`. Во время записи в строке меню — красная точка и время.

## Требования

macOS 15 и новее, Apple Silicon. При первом скриншоте macOS попросит разрешение
«Запись экрана и системного звука», при записи с микрофоном — доступ к микрофону.

## Установка тестовой сборки

1. GitHub → **Actions** → «Qural для Mac» → последний запуск → артефакт **Qural-mac** → распаковать `Qural-mac.zip`.
2. Перенести `Qural.app` в «Программы».
3. Сборка не подписана сертификатом Apple, поэтому macOS её не откроет двойным щелчком. Один раз выполните в Терминале:
   `xattr -dr com.apple.quarantine /Applications/Qural.app` — и запускайте как обычно.
4. Подпись пока ad-hoc: после каждой новой сборки macOS может заново спросить разрешение на запись экрана
   (если не спрашивает, но скриншоты не работают — удалите Qural из списка в настройках и добавьте снова).

## Сборка на Mac

```bash
xcode-select --install          # если нет Xcode
Projects/QuralMac/build.sh      # → Projects/QuralMac/build/Qural.app и Qural-mac.zip
```

## Стек

Swift 5 (Swift Package Manager), AppKit + SwiftUI (окно настроек), ScreenCaptureKit: `SCScreenshotManager` — скриншоты,
`SCStream` + `SCRecordingOutput` — запись с аппаратным кодированием, `SCContentSharingPicker` — выбор окна;
Core Image — размытие; Carbon `RegisterEventHotKey` — горячие клавиши; `SMAppService` — запуск при входе.
Без сторонних библиотек.

| Файл | Что внутри |
|---|---|
| `App.swift`, `AppDelegate.swift` | Запуск, значок и меню в строке меню, горячие клавиши |
| `Shot.swift`, `Marks.swift` | Окно скриншота: выделение, рисование, панель инструментов, сохранение |
| `Recorder.swift` | Запись: экран, область, окно |
| `Panels.swift` | Уведомления и отсчёт перед записью |
| `SettingsView.swift`, `Prefs.swift` | Настройки |
