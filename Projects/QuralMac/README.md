# Qural для Mac

Программа в строке меню macOS для скриншотов с рисованием — как скриншоты в Qural для Windows.
Только скриншоты: цвета мониторов, громкости программ и записи экрана на Mac нет.

Статус: **0.2, тестовые сборки** — проверяется на Apple Silicon.

## Что умеет

- **⌃⌥S — скриншот области.** Наведите на окно — щелчок выделит его; щелчок по пустому месту — весь экран;
  или тяните рамку. Рамку можно двигать и тянуть за ручки. Лупа показывает точки под курсором, цвет и координаты,
  **C** — скопировать цвет (#RRGGBB).
- **Рисование:** карандаш, линия, стрелка, прямоугольник, овал, маркер, текст, размытие (пиксели), номера шагов;
  8 цветов; колёсико — толщина.
- **Подсветка области:** всё вокруг выделенных мест затемняется или размывается (колёсико — сила размытия);
  пересекающиеся подсветки сливаются.
- **Рука:** перетащить любую пометку, ручки — размер (надпись и номер растут без искажений), двойной щелчок по тексту —
  править, колёсико — размер шрифта, стрелки — сдвиг, Delete — удалить.
- **⌘C или Enter** — в буфер, **⌘S** — сохранить в `~/Pictures/Qural` (PNG или JPEG), **⌘Z** — отменить, **Esc** — закрыть.
- **⌃⌥F** — весь экран под курсором сразу в папку (и в буфер).

## Требования

macOS 15 и новее, Apple Silicon. При первом скриншоте macOS попросит разрешение «Запись экрана и системного звука»
(так в macOS называется доступ к снимкам экрана).

## Установка тестовой сборки

1. GitHub → **Actions** → «Qural для Mac» → последний запуск → артефакт **Qural-mac** → распаковать (внутри `Qural-mac.zip`, в нём `Qural.app`).
2. Перенести `Qural.app` в «Программы» (старую версию сначала закрыть: меню Qural → «Выйти»).
3. Сборка не подписана сертификатом Apple, поэтому один раз выполните в Терминале:
   `xattr -dr com.apple.quarantine /Applications/Qural.app` — и запускайте как обычно.
4. Подпись пока ad-hoc: после новой сборки macOS может заново спросить разрешение; если не спрашивает, а снимки не
   получаются — удалите Qural из списка «Запись экрана и системного звука» и добавьте снова.

Если что-то не работает — журнал: `~/Library/Logs/Qural/qural.log` (кнопка «Журнал» в настройках).

## Сборка на Mac

```bash
xcode-select --install          # если нет Xcode
Projects/QuralMac/build.sh      # → Projects/QuralMac/build/Qural.app и Qural-mac.zip
```

Иконка (`Icon.iconset`) рисуется на Windows из значка Qural: `tools/make-icon.ps1`.

## Стек

Swift 5 (Swift Package Manager), AppKit + SwiftUI (окно настроек), ScreenCaptureKit (`SCScreenshotManager`),
Core Graphics (список окон, рисование, вырезание подсвеченных мест), Core Image (пиксели и размытие),
Carbon `RegisterEventHotKey` — горячие клавиши, `SMAppService` — запуск при входе. Без сторонних библиотек.

| Файл | Что внутри |
|---|---|
| `App.swift`, `AppDelegate.swift`, `HotKeys.swift` | Запуск, значок и меню в строке меню, горячие клавиши, журнал |
| `Shot.swift`, `Marks.swift` | Окно скриншота: выделение, окна под курсором, лупа, рисование, «Рука», подсветка, панель |
| `Snapshot.swift` | Снимок экрана и сохранение |
| `Panels.swift` | Уведомления |
| `SettingsView.swift`, `Prefs.swift` | Настройки |
